# 森の子 - 育成ゲーム Prototype

ブラウザだけで動く育成ゲームのシステム検証用プロトタイプです。外部API・LLM・サーバーは不要です。

## 起動
`index.html` をブラウザで開いてください。

## 現在の実装
- 現実1日 = 1歳
- 0〜7歳はお世話が必要、8歳から自立、50歳で基本寿命
- 空腹・清潔のリアルタイム低下とオフライン経過反映
- 食事 / 体を洗う
- 病気 / 回復 / 死亡
- 1日1回の自動ダンジョン
- Level / XP
- 戦闘力 = Level
- 能力3値: 賢さ / 生命力 / 力
- 性格6軸: やさしさ / 勇気 / 好奇心 / 規律性 / 社交性 / 情緒安定性
- 性格の先天基準値と、緩やかな後天変化
- 8歳から仕事選択
- 森の村 / 近くの町の仕事
- 日次自動勤務、収入、能力・XP成長
- LLMを使わない簡易自然言語判定
- 最大8体の村
- LocalStorage保存
- 開発用時間送り

## パラメータ方針

### 能力
先天差はあるが後天的に大きく変わる。
- 賢さ: 学習・判断・技術
- 生命力: 健康・回復・繁殖力
- 力: 筋力・肉体作業適性

### 性格
先天性を中心に、後天的には多少変化する。
- やさしさ
- 勇気
- 好奇心
- 規律性
- 社交性
- 情緒安定性

### 戦闘力
Levelで表現。ダンジョンや肉体労働でXPを得る。

## 仕事
森の村: 農業 / 林業 / 建築 / 木工職人 / 薬草師 / 森の案内人

近くの町: 店員 / 町役場の記録係 / 商会の帳簿係 / 商人 / 宿屋 / 学び舎の先生

詳細は `JOB_SYSTEM.md`。
