# 森の子 — Forest & You

森の村で出会った小さな子を、お世話とことばで育てるブラウザゲームです。
GitHub の最終構想と Google Drive の「育成型ゲーム案」をもとに、まずひと通り遊べる MVP にしました。

## 今すぐ遊ぶ

**`index.html` をブラウザで開くだけ。** インストール、アカウント、APIキーは不要です。
CSS・JavaScript・`assets` フォルダを含め、このフォルダ一式を同じ場所に置いてください。

最初は **「おためしで遊ぶ」** がおすすめです。

1. キツネ・ウサギ・クマ・ネコから最初の子を選び、名前をつける。
2. ごはん、お風呂、声かけでお世話する。
3. 「森を探索」で3つの出来事を選び、金貨とXPを持ち帰る。
4. お世話を済ませて「翌日へ進む」。全員が1歳成長する。
5. 8歳になったら仕事を選ぶ。翌日からも自動でお給料を受け取る。
6. お店で贈りものを買ったり、新しい子を村へ迎えたりして暮らしを続ける。

「はじまりの手帖」の6つの目標が、成人・就職までを案内します。
目標を全部達成した後も、育成を続けられます。

### 2つの時間モード

| モード | 時間の流れ | 向いている遊び方 |
|---|---|---|
| おためし | 「翌日へ」で全員が1歳成長。閉じている間は進まない | 約10分で成長・仕事まで体験する |
| 通常 | 現実1日＝1歳。留守中の時間も反映 | 毎日少しずつ会いに来る |

設定から切り替えられます。**2つの村は別々に保存**されます。
0〜7歳は日々のお世話が必要です。8歳から自立し、50歳で寿命を迎えます。

### ローカルサーバーで遊ぶ場合

Node.js 18以上があれば、次のコマンドでも起動できます。依存パッケージのインストールは不要です。

```sh
npm start
```

ブラウザで http://localhost:4173 を開きます。停止は `Ctrl+C`。
他のアプリが同じポートを使っているときは `PORT=4174 npm start` に変更できます。

## MVPで遊べること

- 4種類の外見、名前変更、息づかい・まばたき・お世話時の動き
- 無料のごはん・お風呂、病気・回復・寿命
- 自然文の声かけ、性格6軸へのゆっくりした変化
- 賢さ・生命力・力、Level / XP
- 能力で結果が変わる、3場面の探索。1体につき1日1回、途中再開も可能
- 8歳からの12種類の仕事、自動勤務と能力成長
- 小さなお店：スープ・薬・個体ごとのスカーフ
- 生存中の仲間は最大8体、旅立った子の記録、4種の出会い記録
- 6つの育成目標、出来事の履歴
- 自動保存、JSONで書き出し・読み込み、旧試作セーブの移行
- PC・スマートフォン向けレイアウト、キーボード操作、動きを抑えるOS設定への対応

声かけは文字n-gramの類似度と小さなルールによる簡易判定です。生成AIとの自由会話ではありません。
外部通信、分析ツール、広告、課金はありません。素材もすべてローカルに含みます。

## 保存について

- データは**同じブラウザ・同じアドレス**のLocalStorageに保存します。別端末との自動同期はありません。
- `file://` で開く場合と `http://localhost:4173` では保存場所が異なります。ブラウザやファイルの置き場所を変えるときは、設定から書き出し・読み込みを使ってください。
- 保存できないブラウザ設定でもその場で遊べますが、閉じる前にデータを書き出してください。画面に保存できない旨を表示します。
- 旧 `pet-game-v1` / `forest-child-prototype-v1` は、同じ保存領域に存在する場合に通常モードへ移行します。元データは削除しません。
- 読み込めない既存データは、新しく始める前に同じブラウザ内の別キーへ退避します。

## 開発・検証

ビルド不要。`game.js` は画面に依存しないゲームルール、`app.js` は画面と保存、`style.css` は見た目です。
背景とキャラクターはSVGで描いています。`assets/forest.svg` が背景、キャラクターは `app.js` の `petSVG` で作ります。

```sh
npm test
```

ゲームルールは Node.js 標準テストランナーで検証できます。
任意のブラウザ受け入れテストは、Playwright 1.62.1 と Google Chrome のある環境で、サーバーを起動したまま `npm run test:browser` を実行します。
Playwrightはゲーム本体にも通常のテストにも必要ありません。スクリーンショットは `/tmp/morinoko-qa` に出ます（`QA_OUTPUT` で変更可能）。
