# 森の子 - 育成ゲーム Prototype

ブラウザだけで動く、育成ゲームのシステム検証用プロトタイプです。
外部API・LLM・サーバーは不要です。

## 起動
`index.html` をブラウザで開いてください。

## 現在の実装
- 1現実日 = 1歳
- 0〜7歳: 子ども。食事・清潔の放置で病気になり、さらに悪化すると死亡
- 8歳〜: 大人。放置しても生存可能
- 50歳: 老衰
- 空腹度・清潔度は現実時間で自然低下（ブラウザを閉じていた時間も再開時に反映）
- 食事
- 体を洗う
- 病気 / 回復 / 死亡
- ダンジョン: 1日1回、自動結果、G・XP・性格変化
- レベルアップ
- 戦闘力 = レベル
- 賢さ（0〜100）
- 8歳から仕事を設定可能
- 設定した仕事は現実1日ごとに自動処理
- 森の村 / 近くの町の複数仕事
- 声かけ: LLMなし。文字n-gramベクトル + cosine類似度 + 小さなルール補正
- 性格7軸: やさしさ / 勇気 / 好奇心 / 規律性 / 社交性 / 情緒安定性 / 生命力
- 最大8体の村
- 森で保護する簡易加入
- LocalStorage自動保存
- 開発用の+8時間 / +1日時間送り

## 性格と能力

### 性格7軸
- やさしさ
- 勇気
- 好奇心
- 規律性
- 社交性
- 情緒安定性
- 生命力

### 能力
- 賢さ: 0〜100
- 戦闘力: Level

生命力は戦闘力とは別です。
生命力は将来的に出生確率、病気耐性などへ使用します。
戦闘力はダンジョンと肉体労働系の仕事で上昇します。

## 仕事
8歳から仕事を設定できます。

森の村:
- 農業
- 林業
- 建築
- 木工職人
- 薬草師
- 森の案内人

近くの町:
- 店員
- 町役場の記録係
- 商会の帳簿係
- 商人
- 宿屋
- 学び舎の先生

仕事により、お金・戦闘XP・賢さ・一部性格が変化します。
詳細は `JOB_SYSTEM.md` を参照してください。

## 仕様上の解釈
会話中に「10日で成人」と「7歳までは子ども、8歳以上で子どもを作れる」が混在したため、
後に示されたルールを優先して「8歳で成人・自立」としています。
