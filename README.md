# 森の子 - 育成ゲーム Prototype

ブラウザだけで動く、育成ゲームのシステム検証用プロトタイプです。
外部API・LLM・サーバーは不要です。

## 起動
`index.html` をブラウザで開いてください。

## 現在の実装
- 1現実日 = 1歳
- 0〜7歳: 子ども。食事・清潔の放置で病気になり、さらに悪化すると死亡
- 8歳〜: 大人。放置しても生存可能
- 50歳: 老衰
- 空腹度・清潔度は現実時間で自然低下（ブラウザを閉じていた時間も再開時に反映）
- 食事（ボタン操作で空腹度を回復。画面に変化量を表示）
- 体を洗う（ボタン操作で清潔度を回復。画面に変化量を表示）
- 病気 / 回復 / 死亡
- ダンジョン: 1日1回、自動結果、G・XP・性格変化
- レベルアップ
- 声かけ: LLMなし。文字n-gramベクトル + cosine類似度 + 小さなルール補正
- 性格7軸: やさしさ / 勇気 / 好奇心 / 規律性 / 社交性 / 情緒安定性 / 生命力
- 最大8体の村
- 森で保護する簡易加入
- LocalStorage自動保存
- 開発用の+8時間 / +1日時間送り

## 性格について
現プロトタイプでは7軸を0〜100で保持します。

- やさしさ
- 勇気
- 好奇心
- 規律性
- 社交性
- 情緒安定性
- 生命力

生命力と社交性は、将来の結婚・次世代システムにも使用する予定です。
生命力が高いほど子どもを持ちやすく、社交性と生命力が高い個体ほど結婚・次世代形成へ進みやすい設計を検討しています。
