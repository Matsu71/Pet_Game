# 森の子 - 育成ゲーム Prototype

ブラウザだけで動く、育成ゲームのシステム検証用プロトタイプです。
外部API・LLM・サーバーは不要です。

## 起動
`index.html` をブラウザで開いてください。

## 現在の実装
- 1現実日 = 1歳
- 0〜7歳: 子ども。食事・清潔の放置で病気になり、さらに悪化すると死亡
- 8歳〜: 大人。放置しても生存可能
- 50歳: 老衰
- 食事（ボタン操作で空腹度を回復。画面に変化量を表示）
- 体を洗う（ボタン操作で清潔度を回復。画面に変化量を表示）
- 病気 / 回復 / 死亡
- ダンジョン: 1日1回、自動結果、G・XP・性格変化
- レベルアップ
- 声かけ: LLMなし。文字n-gramベクトル + cosine類似度 + 小さなルール補正
- 性格: やさしさ / 勇気 / 好奇心 / 規律 / 社交性
- 最大8体の村
- 森で保護する簡易加入
- 開発用の内部パラメータ常時表示（空腹・清潔・体力・放置時間・病気・XP・性格5軸・行動回数など）
- LocalStorage自動保存
- 開発用の+8時間 / +1日時間送り
