# 家族・世代システム チェックポイント

2026-09-11 時点の `main` v0.9 を基準に、未反映だった家族・世代システムを通常のGitコミットとして再構築した作業記録です。

## 今回反映するもの

- `family.js`
  - 親密度70以上・双方8歳以上を家族関係の条件にする。
  - 1体が同時に複数の有効なパートナーを持たない。
  - 別離後も過去の関係記録を保持する。
  - 村の上限8体を超える出生を防止する。
  - 同じ組み合わせで同日に重複出生できない。
  - 子どもの能力・性格の先天値を両親から緩やかに継承する。
  - 出生時3%で、現在未発見のベース種を優先する突然変異枠を持つ。
  - 親・子・パートナー・世代番号を取得できる。
  - 旧v2セーブでは `family` が無くても有効とする。
- `tests/family.test.cjs`
  - 成人・親密度条件、重複パートナー防止、出生、村上限、同日重複防止、別離、破損家系データ拒否を検証する。

## 次の実装対象

- 結婚・出生のスマートフォンUI。
- 20種類すべてのキャラクターアート。
- 耳・顔・体・尾などを部位単位で合成する外見遺伝。
- 出生確率を生命力・年齢・生活環境から計算する高度なシミュレーション。
- 旅立ち時にパートナーも同伴する最終仕様。
